## Before you start

The Generator path needs TRON FullNode and SolidityNode wallet API access. The Host path begins with a compatibility check because the reviewed Host release has not been validated against the TRON data model. Follow the prerequisites for the path you choose.

TRON Generator registration requirements are not yet confirmed. Complete the ingestion checks before pursuing public registry onboarding.
